# Исправления и перепроверка — 3 ноября 2026

Исправлены семь ошибок из предыдущего разбора. Изменены `storage.py`, `recommender.py`, `competitors.py`, `population.py`, `aggregator.py` и `run_engine.py`. Добавлен набор проверок `tests/test_engine_regressions.py`.

## Результат

1. Бюджет, площадь, ставка и радиус поиска соблюдаются строго. Автоматическое расширение удалено. Совпадение ключевых слов адреса также не позволяет выйти за радиус. Пустой результат сохраняет исходные параметры клиента.
2. Загрузка Карт различает успешные, частичные, пустые и недоступные данные. Неполная AI-классификация тоже помечается. Пустые ответы больше не означают «свободную нишу» и не дают 92 балла за конкуренцию.
3. Население и доходы больше не подставляются из общего справочника при отсутствии исходных данных. Отчёт называет только использованные источники. При отсутствии данных интерфейс показывает «н/д» и пояснение; расчётные доходы при наличии цен жилья явно названы модельной оценкой.
4. Повторный сбор обновляет все сохраняемые изменяемые поля объявления и его сигнатуру вместе с R-Tree в одной транзакции. При открытии хранилища исправляются отсутствующие или рассинхронизированные индексные записи по координатам основной таблицы.
5. Выручка сопоставленных юридических лиц сохраняется полностью, учитывается один раз на ИНН и отображается как отчётность юрлиц. Ограничение до 250 млн ₽ и положительный вклад этой выручки в рейтинг локального спроса удалены. Текст о выручке «на точку» удалён.
6. Период ставки теперь явный. Годовая ставка 6 000 ₽/м² остаётся 6 000 ₽/м²/год. Добавлены `--price-sqm-year` и `--price-sqm-period`; по умолчанию `--price-sqm` означает месячную ставку.
7. Отказ отдельного кандидата или финансового обогащения сохраняет остальные результаты. Ошибки отражаются в отчёте. Неизвестный этаж получает нейтральную оценку и пометку для уточнения.

Дополнительно: нераспознанная локация больше не заменяется молча центром Москвы. Рейтинг обозначен как сравнение проверенных кандидатов. Высокий расчётный балл означает приоритет для просмотра; при неполных данных вывод прямо требует уточнения.

```powershell

```

## Пределы проверки

Внешние API в этих проверках заменены контролируемыми ответами. Фактическая доступность источников, полнота реальной выдачи, точность оценки потока, жителей и доходов, а также задержка обнаружения новых объявлений здесь не измерялись.

Сохранённый географический выброс Инвестпортала не исправлялся догадкой: правильные координаты требуют сверки с источником. Строгий радиус исключает его из московского подбора.

Фоновый мониторинг, Telegram-оповещения, EXE и другие города не входили в исправление ошибок и пока требуют отдельной реализации.

Совместимость: числовые поля старого отчёта сохранены, поэтому нулевые значения при отсутствии сведений нужно читать вместе с `data_status`, флагами доступности и `data_warnings`. Старые имена полей агрегированной выручки сохранены; они содержат выручку сопоставленных юрлиц, а не оценку локальных точек.
