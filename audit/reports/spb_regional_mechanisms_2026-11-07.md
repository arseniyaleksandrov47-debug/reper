# Адаптация механизмов под Санкт-Петербург — 7 ноября 2026

Перенесены общие механизмы и подключены местные источники. Полного покрытия местных данных и подтверждённого лучшего помещения пока нет. Формула, требования из свободной концепции, обязательные ограничения и проверки доказательств остаются общими для городов; правил под конкретную нишу или адрес не добавлено.

## Реализовано

1. **Сеть и Happ.** Исправлен общий мост Windows: помимо HTTPS CONNECT он теперь передаёт обычные HTTP-запросы, сохраняет тело запроса, корректно обрабатывает разделённые заголовки и не отправляет данные авторизации прокси целевому серверу. Это устранило воспроизводимый сбой городского источника — через прежний мост он немедленно получал пустой ответ, через обычное соединение отвечал HTTP 200. В оба профиля `%LOCALAPPDATA%/Happ/routing.json` добавлены прямые доменные правила для `78.rosstat.gov.ru`, `metro.spb.ru`, `commim.gov.spb.ru`, `torgi.gov.ru`. Резервная копия: `backups/routing-before-spb-regional-20261107-184816.json`. Общее правило `.ru` в активном профиле уже существовало; добавление исключений не доказывает исправность самого источника.
2. **Домклик.** При ошибке доступа полной карточки выполняется ограниченный повторный запрос существующего городского арендного каталога тем же сборщиком. Допускается только точный ID с согласованными городом, регионом, адресом, площадью и текущей публикацией. Опубликованные аренда, этаж, описание и фотографии доступны проверке; подтверждение арендодателя из этого не следует. Исправлены относительные ссылки фотографий: повторный `/vitrina/` больше не добавляется. Живая фотография возвращает HTTP 200 и `image/jpeg`.
3. **Муниципальная аренда.** Новый источник читает текущие извещения ГКУ имущества и привязанные к ним структурированные карточки федеральных торгов. В живой проверке получено 8 лотов с открытым приёмом заявок. Проверяются регион 78, тип аренды, категория нежилого объекта, сроки, валюта, площадь и координаты. Годовая начальная ставка переводится в месячную по явно указанному периоду цены. Она сохраняет пометку стартовой ставки, а не окончательной аренды. Архивные, приостановленные, аннулированные и ещё не открытые торги не становятся текущими предложениями.
4. **Метро.** Адаптер сам находит последний отчёт оператора за завершённый год. В [отчёте за 2025 год, PDF-страница 7](https://metro.spb.ru/uploads/document/LAB_GO_METRO_2025_interactive.pdf#page=7) опубликованы среднесуточные значения 10 станций. Источник не разделяет вход и выход; вместо точечного числа входящих используется диапазон 0…опубликованное значение. Неизвестным станциям значения не назначаются. Сохраняются дата, страница, SHA256 и неполное покрытие; срок актуальности — 366 дней. В конце проверки также исправлена подпись источника в `ai_response_metadata`: она теперь соответствует выбранному региональному адаптеру, включая ветку без карточек организаций. В сохранённых снимках сквозного прогона до этого последнего исправления подпись ошибочно указывала московский источник; сами снимки не переписывались.
5. **ФНС.** К коротким адресам карт добавляется город по координатам до поиска юрлица. Явный конфликт города с координатами запрещает привязку. Живая проверка 4 петербургских заведений вернула местных кандидатов юрлиц, но не доказала принадлежность: 0 финансовых профилей присвоено. Отдельная проверка ФНС по одному из кандидатов получила HTTP 200 с пустым списком, а не ошибку маршрута. Совпадение адреса и ОКВЭД по-прежнему недостаточно для переноса выручки компании в рейтинг точки.
6. **Жители зданий.** Добавлен общий `POPULATION_DATA_FILE`: датированные наблюдения с происхождением, ID здания, координатами и числом жителей. Проверяются формат, уникальность ID, дата и координатная привязка. Частичный набор не становится суммой всего окружения; пропуски не подменяются нулями или московскими коэффициентами. Реальный местный набор не получен: [страница Петростата](https://78.rosstat.gov.ru/folder/29062) продолжает возвращать таймаут. Импорт проверен на контролируемых данных; наличие реального петербургского набора не заявляется.
