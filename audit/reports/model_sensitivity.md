# Автоматическая проверка сценарных допущений — 8 ноября 2026

Проверка спорных коэффициентов встроена в обычный клиентский подбор. Ранее
отдельный аудит находил перестановки, а клиент получал общие предупреждения
об устойчивости данных и весов. Теперь отчёт сохраняет причину перестановки,
исходное и проверочное значение коэффициента, оценки сравниваемых вариантов
и ID альтернатив. Объяснение в консоли выводится один раз.

## Поведение

Проверка выполняется после уточнения опубликованных условий, обновления цен,
отсева неподходящих объявлений и группировки дублей. Она использует весь
проанализированный оставшийся пул, включая варианты за пределами основного
лимита отображения. В блок сопоставимых вариантов входят альтернативы по
данным, весам и модельным предположениям; последние получают место в этом
блоке в первую очередь. Предыдущие предупреждения о выбывших вариантах удаляются.

Для каждого незакреплённого опорного уровня, `competition_scale`,
`outside_pressure` и активного опорного времени доступности проверяются
множители ×0,5 и ×2 по одному параметру за раз. Веса критериев, условия допуска,
данные объявления и окружения сохраняются. Клиентские и предоставленные
контрольные ориентиры фиксируются по полям: один заданный ориентир не
отключает проверку остальных предположений.

При смене лидера результат полного сравнения становится `comparable`.
При недостающих исходных данных сохраняется `needs_data`. Если сама проверка
не выполнена, отчёт сообщает `model_sensitivity_unavailable`; успешная
устойчивость не подразумевается. Показ альтернативы не подтверждает её
непроверенные условия: соответствующая пометка сохраняется.

Добавлена регрессия для верхней границы допустимого коэффициента: технический
лимит ввода не запрещает конечное положительное стрессовое значение за этой
границей. Базовый профиль при этом не меняется.

- **21 сохранённый отчёт, 30 оценок, 17 разных объявлений**: повторный расчёт

  Исходный отчёт имел статус `needs_data`.
- **500 контрольных пар / 7000 изменений коэффициентов**: обнаружены все
  **97** перестановок первой позиции; пропусков — 0, ошибок механизма — 0.
- Снижение аренды и увеличение доступной аудитории проверены в 81 направленном
  сравнении; нарушений монотонности — 0.
- Ruff F401/F811/F821/F823/F841 — OK.

Ориентир накладного времени по этому запуску: медиана около **5 мс** на

Сеть и ИИ для проверки коэффициентов не используются. Время зависит от
числа вариантов и сложности сохранённых маршрутов.
